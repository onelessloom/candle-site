# candle-site

Public pages for the Candle (蠟燭) iPhone app, served by GitHub Pages:

- Privacy policy: https://onelessloom.github.io/candle-site/privacy.html
- Support: https://onelessloom.github.io/candle-site/support.html

The source of `privacy.html` and `support.html` is `site/` in the app's repository; copy changes from there.
`.nojekyll` makes Pages serve the files as they are.
